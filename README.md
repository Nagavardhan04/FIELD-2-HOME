# FIELD 2 HOME
## BHOOMI TO BHAVAN

A Direct Farmer-to-Customer Grocery Marketplace built using Python, Streamlit and Firebase.

## Features
- Customer registration and login
- Farmer registration and verification
- Admin dashboard
- Product marketplace
- Shopping cart and checkout
- Cash on Delivery
- Order management
- Delivery partner management
- Google Maps integration
- Order tracking

## Technologies Used
- Python
- Streamlit
- Firebase Authentication
- Cloud Firestore
- Google Maps API

## Project Purpose
To connect farmers directly with customers, reduce intermediaries and make fresh agricultural products accessible.
